## About Zorara

Zorara is a Windows desktop tool for Roblox scripting, combining Lua injection, Luau execution, and a straightforward application workflow. Users can load scripts, search the built-in hub, and organize executions from a clean, uncluttered interface.

The application is designed for native Windows use and includes an auto-update engine, a queue that remains stored between sessions, and an integrated debugger. Its 500+ script collection and multilingual interface make it a practical scripting utility for Windows 10 and 11.
